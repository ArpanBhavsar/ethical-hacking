Part 3 — NULL/FIN/Xmas & hping3 (Do together after Sections 2–3 · Nmap types & hping3)

See RFC 793 odd-flag behaviour and craft single packets with hping3.
  • Run sudo nmap -sN -p 9021,9022,9025,9080,9099 -oN scans/ccx-null.nmap 127.0.0.1 (or the same ports on MS2). Repeat with -sF or -sX once.

Why it works. Classic stacks RST closed ports on odd flags and stay silent on open ports; many modern stacks blur this into open|filtered — document uncertainty instead of inventing certainty.

Part 4 — Safe NSE (Do together after Section 3 · NSE)

Run named safe/default scripts against ports you already know are open.
  • Fallback: nmap -sT -sV -p 9025,9080 --script smtp-commands,http-title,http-robots.txt -oN scans/ccx-nse.nmap 127.0.0.1
  • MS2: pick two open ports from Part 2 and run appropriate safe scripts (e.g. smb-os-discovery, http-title).
  • Record script names and key lines (VRFY advertised? robots Disallow paths?).
Show solution

Verified fallback NSE showed Postfix advertising VRFY, HTTP title “CyberCorp Kelowna Intranet”, and robots Disallow for /portal/admin/ and /backup-2025/. See lab-assets/sample-output/ccx-range-nse.nmap.

Why it works. Named scripts beat blanket --script vuln on day one of Phase 2a.

Part 5 — Service enumeration (Do together after Section 4 · enumeration)

Extract users, MIB data, zone records and shares — CEH enumeration phase.
  • SMTP: Use the manual dialogue pattern from lecture or nmap --script smtp-enum-users with lab-assets/wordlists/ccx-usernames.txt against fallback port 9025 (or MS2 port 25).
  • SNMP (fallback extras): snmpwalk -v2c -c public 127.0.0.1:1161 1.3.6.1.2.1.1
  • DNS AXFR (fallback extras): dig @127.0.0.1 -p 5353 cybercorp.example AXFR then the same for corp.cybercorp.example. Contrast refuse vs leak.
  • SMB: enum4linux-ng -A <target> and/or smbclient -L //<target> -N (MS2 or fallback with --smb).
  • LDAP (optional extras): ldapsearch -x -H ldap://127.0.0.1:3890 -b ou=People,dc=corp,dc=cybercorp,dc=example uid cn title description
