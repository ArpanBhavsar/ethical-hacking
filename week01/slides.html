Presentation controls

Use ← / → or Page Up / Page Down to navigate. Home / End moves to the first / last slide.

M opens sections. O opens overview. R toggles all-slides view. F toggles fullscreen. Escape closes navigation.

P opens synchronized speaker notes in a separate window. Share only the presentation window with students. Allow pop-ups if your browser blocks the presenter window. Use the notes window’s navigation buttons to advance both windows.

Download the HTML and open it in your browser for full interaction. All lesson content works offline. Reference links need Internet access.

Use Ctrl/Cmd + P to print the complete reading material. Reveal the worked solutions first if you want them in the printout. Activity responses remain in this page while it is open.
